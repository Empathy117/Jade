# Phase 4 体验闸门

> 状态：已通过（个人自用范围）
> 负责人：项目维护者  
> 最近更新：2026-08-20

## 结论先行

Phase 4 不验证“界面是否漂亮”，而是验证沉浸演出是否帮助阅读，以及哪些
规则应先进入 Agent 制书协议，并在未来条件成熟时进入 Matcher 和 Compiler。

原计划在进入自动化阶段前完成至少 5 次完整阅读观察，其中至少 3 名体验者
此前没有使用过本项目。项目维护者确认本项目当前是个人自用工具，不以验证
大众适用性为目标，因此 2026-08-20 接受单用户证据并通过闸门：维护者已完整
读完 Demo，关键体验问题均已处理，音乐替换后复测进一步改善。

原样本要求保留为未来公开发布或服务其他读者时的重新验证条件，不再阻塞
个人版本进入自动化阶段。

## 体验目标

每次观察需要回答四个问题：

1. 体验者能否不经解释完成阅读？
2. 背景、音乐和环境音是在增强情境，还是在争夺注意力？
3. 文字累积、自动滚动和清屏是否保持了阅读连续性？
4. 哪些演出规则值得固化为自动编排约束？

本阶段不比较 AI 模型，不评价自动分场，也不新增与体验验证无关的功能。

## 单次观察流程

建议每次预留 15–20 分钟。

### 1. 准备

- 使用桌面浏览器打开 Reader；
- 选择“从头开始”；
- 使用默认字号、音量和动态设置；
- 不提前讲解快捷键，只告知“请按你觉得自然的方式读完”；
- 观察者不要在阅读中解释设计意图。

### 2. 静默观察

只记录可观察行为，不立即追问原因：

- 首次推进使用了点击、空格还是按钮；
- 是否出现停顿、误操作或不知道如何继续；
- 是否手动滚动、返回、打开历史或调整设置；
- 是否在某个背景、音乐、环境音或清屏节点明显分心；
- 是否静音、启用纯净阅读或减少动态；
- 是否完整读完。

### 3. 阅读后访谈

按顺序询问，避免先暗示“沉浸感”：

1. 整体读起来怎么样？
2. 有没有哪一刻让你从故事里跳出来？
3. 背景、音乐、环境音分别有什么帮助或干扰？
4. 新文字出现的位置、旧文字的明暗和清屏节奏怎么样？
5. 如果继续用它读另一篇小说，你最希望保留什么、减弱什么、去掉什么？
6. 普通阅读和这个版本，你会在什么情况下选择其中一个？

### 4. 记录

复制 [体验记录模板](experience-session-template.md)，每名体验者保存一份独立
记录。原话可以短句引用，但“观察事实”和“观察者解释”必须分开。已完成记录
保存在 [`experience-sessions/`](experience-sessions/) 目录。

## 已确认的演出规则

这些规则已有直接体验证据，后续实现不得无意回退：

| 规则 | 状态 | 理由 |
|---|---|---|
| 当前段落底边停靠在窗口约 77% 位置 | 保留 | 避免进入底部渐隐区，并保留下一段生长空间 |
| 点击或空格逐段主动推进 | 保留并视为核心交互 | 首次完整阅读中被评价为显著提升愉悦感 |
| 旧段落降低强调、当前段落保持纯白 | 暂时保留 | 当前反馈认为阅读舒适，仍需首次体验者验证对比度 |
| 阅读历史只包含已读内容 | 保留 | 允许回顾且不提前暴露正文 |
| 回看历史不覆盖最远阅读进度 | 保留 | 回顾行为不应破坏恢复位置 |
| 场景边界与清屏独立 | 暂时保留 | 当前 Demo 未出现阻断反馈，仍需逐场景观察 |

## 待验证的演出预算

以下是观察时重点验证的候选值，不是最终结论：

| 项目 | 当前候选 | 需要观察的信号 |
|---|---|---|
| 背景 crossfade | 1.4–2.2 秒 | 是否注意到切换本身而中断阅读 |
| BGM 默认音量 | 总音量 90%，音乐通道 55% | 是否主动调低或静音，是否盖过内在阅读声音 |
| 环境音默认音量 | 总音量 90%，环境通道 50% | 是否能感知但不抢注意力 |
| 背景保持 | 原则上至少一个语义场景 | 是否出现“像 MV 一样频繁换画面” |
| BGM 保持 | 可以跨越多个相邻场景 | 情绪变化是否足以支撑换曲 |
| 页面失焦 | 250ms 内降到轨道音量 35%，返回时恢复，不重置曲目 | 是否仍过响；切回页面时是否突兀 |

## Phase 4 结论

个人自用范围内，以下条件已经满足：

- 项目维护者完成全文阅读，未发现阻断阅读的问题；
- 点击逐段推进被确认为最强的核心体验增益；
- 背景与真正的音乐均带来正向增益，且没有显著打断阅读；
- 所有高影响反馈已经修复，或有明确拒绝理由；
- 背景、BGM、环境音和清屏都有可执行的保持与切换默认值；
- 纯净阅读仍然完整可用。

演出决策：

- **保留**：主动逐段推进、克制的场景背景、悦耳且可持续的 BGM、阅读历史；
- **减弱**：旧段落强调、过于频繁的素材切换、持续存在的环境音；
- **移除**：以程序合成占位音冒充 BGM 的方案；
- **限制**：环境音和 SFX 仅在语义合适时偶发出现，不替代音乐。

当前默认预算沿用已完成全文验证的 Demo 参数：背景按语义场景保持，BGM 可跨
相邻场景保持，背景 crossfade 使用 1.4–2.2 秒区间，页面失焦时在 250ms 内
降至轨道音量的 35%。如后续个人阅读中出现反例，作为新证据直接修正规则。

结论：Phase 4 通过，允许进入 Phase 5。若未来面向其他读者发布，必须恢复
5 次完整阅读、至少 3 名首次体验者的原始样本要求。
